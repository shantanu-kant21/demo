📖 About This Repository

Hi there! 👋 This repository holds the basic Python source code I wrote while learning Dictionaries and Sets in Chapter 5 of my Python course.

I'm a second-year BCA student, and this repo is my practice notebook: every file is a small, simple program that helped me understand how Python stores and handles data. If you're a beginner like me, feel free to read, run, and learn from it!

💡 Why dictionaries? Think of a dictionary like your phone's contact list: you look up a name (key) and get a number (value). Python dictionaries work exactly the same way!

✨ Quick Example
python
# Creating a dictionary and updating it
dict = {}
dict.update({
    "Rhythm": "C++",
    "Kartikay": "Python",
    "Shantanu": "C++",
    "Ranjeet": "C++"
})

print(dict)

Output:

{'Rhythm': 'C++', 'Kartikay': 'Python', 'Shantanu': 'C++', 'Ranjeet': 'C++'}

Here, each name is a key and each favourite language is a value. 🎉
